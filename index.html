로그인 계정-

은행 문자 연결하기

아이폰에서 한 번만 해 두면, 입금 문자가 올 때마다 꿀꿀이가 알아서 반응해요.

  1. 위의 꿀꿀이 코드를 복사해요.
  2. 꿀꿀전송 단축어 받기를 눌러 '단축어 추가'를 누르고, 코드를 묻는 칸에 붙여넣어요.
  3. 단축어 앱 → 자동화 → + → 메시지 → '메시지 포함'에 입금 입력 → 즉시 실행 선택 → 다음
  4. 꿀꿀전송을 고르면 끝이에요. 빈 자동화가 열리면 '단축어 실행'을 추가해 꿀꿀전송을 고르고 입력을 메시지로 정해 주세요.
꿀꿀전송 단축어 받기

단축어 링크가 아직 등록되지 않았어요. 관리자에게 물어봐 주세요.

연결을 끊으면 이 계정에서 꿀꿀이가 사라져요. 저금통 바닥 QR로 언제든 다시 연결할 수 있어요.
